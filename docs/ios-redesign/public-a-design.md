# 随记 iOS：以对话为首页的本机助手（设计）

> ⚠️ **重大产品缺口：无邀请码模式没有任何 AI 回答，也没有同步。** 本机对话只做记录、存任务/记忆和逐字查找，不是完整的 AI 助手，没有满足「去掉邀请码后仍有 AI」的需求。AI 问答只在可选云端账户里，而云端账户仍**必须用邀请码**登录。本版本**不含语音听写**。App 不显示任何伪造的 AI 回复或同步状态。

基线：`93729ff`（`feat/ios-minimal-verify`）。取代旧版纸面设计 `01-kimi-ios-design.md`。

## 1. 设计命题

- **对话即首页**：打开即可用，无需邀请码、不发起网络请求。底部是真实输入栏；发出的消息留在对话里，任何一条都可显式「存为任务 / 存为记忆」。
- **诚实的本机边界**：对话顶部说明「本机对话 · 离线可用 · 未同步」及「没有 AI 自动回复」，输入栏下方常驻「仅保存在本机 · 未同步」。
- **真实持久的任务与记忆**：版本化 JSON 文件原子写入；可新建、编辑、完成、删除/忘记；查找是逐字匹配，并标注「不是 AI 理解」。
- **云端账户是另一件事**：左上角「云端账户（可选）」打开独立 Sheet，沿用既有邀请码登录、云端笔记与提问。云端代码不引用本机数据，连接云端不会上传本机内容。
- **视觉**：系统语义色（随深浅色自适应），系统蓝为主色，SF Symbols、Dynamic Type，宽屏限宽 720pt。移除强制浅色、纸面色板和永久禁用的语音假按钮。

## 3. 信息架构

```
RootView（NavigationStack，tint = 系统蓝）
├─ ConversationView（首页）
│   ├─ 边界说明卡：本机 · 离线 · 未同步 · 无 AI 回复
│   ├─ 只读问题卡（存储只读时，含「重新读取」）/ 欢迎卡（空对话时）
│   ├─ 消息行 × N：气泡 + 「存为任务」「存为记忆」/「已存为…」+ 删除菜单
│   └─ 输入栏（底部固定）：输入框、发送、状态行
├─ LibraryView（Sheet）：任务 / 记忆分段、逐字查找、新建 / 编辑 / 完成 / 删除·忘记
└─ CloudAccountView（Sheet，可选）：既有登录 / 云端笔记 / 设置
```

`AppModel`（云端）与 `LocalModel`（本机）都由 `RootView` 持有：关闭云端 Sheet 不会丢失进行中的保存、未完成记事卡和问答「重新提问」入口。冷启动只读取已有 token，不发请求，直到用户打开云端 Sheet。

## 4. 持久化契约（`LocalStore.swift`，只依赖 Foundation）

| 情况 | 行为 |
| --- | --- |
| 读取错误明确是「文件不存在」 | 首次使用：空文档，不创建文件，可写 |
| 正常读取 v1 | 载入 |
| 其他读取错误（权限、文件保护、父目录不可访问、路径是目录等） | **只读**，不清空、不覆盖；「重新读取」成功前拒绝一切写入 |
| JSON 无法解析 / version < 1 | **只读**，原字节不动 |
| version 高于当前（未来版本） | **只读**，原字节不动，提示升级 |
| 写失败 | 抛错，内存与界面保持写盘前状态，显示「本次操作没有保存」 |

- 写入：`Data.write(options: [.atomic, .completeFileProtectionUntilFirstUserAuthentication])`，位置 `Application Support/LocalAssistant/local-store.json`。
- 每次变更都在副本上修改，写盘成功后才更新界面；编辑器保存失败时不关闭、保留输入。
- 草稿与条目同文件：输入后 0.6 秒防抖写盘，离开前台立即写；失败时状态行提示。重新读取成功后，磁盘旧草稿与只读期间的新输入不同则合并（旧在前）。
- 不提供重置或删除现有数据的流程。本机文件会随用户自己开启的 iOS / iCloud 备份一起备份，这是系统行为，不是本 App 的同步。

## 5. 能力与安全矩阵

| 能力 | 状态 | 边界 |
| --- | --- | --- |
| 本机对话（文字） | 可用 | 无需登录、无网络、1–5000 字 |
| 存为任务 / 记忆，编辑、完成、删除/忘记 | 可用 | 仅本机；失败如实提示并回滚 |
| 逐字查找 | 可用 | 包含即匹配（忽略大小写、全半角），不是语义检索 |
| AI 回复（本机） | **无（重大缺口）** | 不显示伪造回复 |
| 语音听写 | **无** | 本版本没有麦克风/语音权限，也没有相关代码 |
| 本机 → 云端上传 / 同步 | **无** | 云端代码不引用本机类型（静态检查强制） |
| 云端登录、笔记、提问、重试 | 可用（沿用） | 需邀请码；会话代次、`client_note_id` 幂等、401 处理未改 |
| 云端语音、提醒、闹钟 | 未接入 | 仅文字说明，无假按钮 |

## 6. 已知缺口与延后项

1. **无邀请码模式没有 AI，也没有同步**（最大缺口）。
2. **P2 延后**：云端 token 仍在 UserDefaults，未迁移 Keychain。
3. **P2 延后**：顶部边界卡与只读问题卡位于滚动区内，长对话时可能滚出视口（底部状态行仍提示本机/只读）。
4. **P2 延后**：任务完成按钮最小 32pt、消息行使用小号控件，未全部达到 44pt 点击区。
5. 本机数据无导出、无跨设备；损坏文件需开发者协助恢复（有意不提供覆盖/重置）。
6. 仅简体中文；工程无 XCTest target，存储自测以独立 `swiftc` 程序提供。
7. `ci / Build & Test` 不构建 iOS，绿灯不代表 iOS 可编译。

## 7. 未来访问方案（仅提案，未实现）

以下两条只是方向，都没有实现，也不涉及后端改动或付费服务：

- **设备端模型（有条件）**：在支持的系统和设备上使用 Apple 的设备端模型，先检查可用性和语言支持，不可用时如实说明。这不是 iOS 17 能力，中国大陆和简体中文的可用性尚未核实。
- **Sign in with Apple 开户**：另行设计，用明确的身份替代邀请码开户，复用现有用户/设备/会话隔离与 `get_auth`，并设配额；新用户永远是新账号，不得访问已有账号的数据。需要单独的后端设计、评审与测试。
